# Vortex brand

| File | Use |
|---|---|
| `mark-*.svg` | The mark alone |
| `*-simple.svg` | The mark without its cuts, for 32 px and below |
| `lockup-horizontal-*.svg` | Mark and name side by side |
| `lockup-vertical-*.svg` | Mark above the name |
| `app-icon-*.svg`, `app-icon-*/` | The app icon, 16–1024 px |

`-light` is for light backgrounds (dark ink), `-dark` for dark backgrounds
(light ink), `-mono-black` / `-mono-white` a single color.

Colors: on light `#15171B` front, `#6B707A` back; on dark `#EDEEF0` front,
`#7C808A` back; icon tile `#1A1B1E` (dark) or `#FFFFFF` (light). The name is
set in Space Grotesk Bold (SIL Open Font License), outlined in the SVGs.

`assets/macos/Vortex.icns` is built from `app-icon-dark/` with `iconutil`.
